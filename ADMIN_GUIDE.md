# Инструкция для администратора CMS

## Введение

Данное руководство предназначено для администраторов контента, работающих с системой управления контентом (CMS) на базе Strapi. Руководство описывает основные функции CMS и порядок работы с контентом сайта Общественной палаты Владимирской области.

## Доступ к админ-панели

1. Перейдите по адресу: `http://your-domain.com/admin`
2. Введите логин и пароль, полученные от системного администратора
3. При первом входе вам будет предложено изменить пароль

## Интерфейс админ-панели

### Главная панель
- **Content Manager** - управление контентом
- **Media Library** - управление медиафайлами
- **Plugins** - настройки плагинов
- **General** - общие настройки
- **Users & Permissions plugin** - управление пользователями и правами

## Работа с контентом

### Создание новости

1. Перейдите в **Content Manager** → **News Collection**
2. Нажмите кнопку **Create new entry**
3. Заполните поля:
   - **Title** - заголовок новости (обязательно)
   - **Description** - краткое описание (обязательно)
   - **Content** - полное содержание новости (обязательно)
   - **Image** - изображение (необязательно)
   - **Date** - дата публикации (обязательно)
   - **Slug** - URL-идентификатор (генерируется автоматически)
   - **Tags** - теги для новостей (необязательно)
4. Нажмите **Save**
5. Для публикации нажмите **Publish**

### Создание анонса мероприятия

1. Перейдите в **Content Manager** → **Announcements Collection**
2. Нажмите кнопку **Create new entry**
3. Заполните поля:
   - **Title** - заголовок анонса (обязательно)
   - **Description** - краткое описание (обязательно)
   - **Content** - полное содержание (обязательно)
   - **Image** - изображение (необязательно)
   - **Date** - дата публикации (обязательно)
   - **Event Date** - дата проведения мероприятия (обязательно)
   - **Location** - место проведения (необязательно)
   - **Slug** - URL-идентификатор (генерируется автоматически)
4. Нажмите **Save**
5. Для публикации нажмите **Publish**

### Добавление документа

1. Перейдите в **Content Manager** → **Documents Collection**
2. Нажмите кнопку **Create new entry**
3. Заполните поля:

## Работа с медиафайлами

### Загрузка изображений

1. Перейдите в **Media Library**
2. Нажмите кнопку **Upload new asset**
3. Выберите файлы с компьютера
4. Заполните **Alt text** для каждого изображения (важно для SEO и доступности)
5. Нажмите **Save**

### Управление файлами

- **Просмотр**: кликните на файл для просмотра
- **Редактирование**: нажмите кнопку редактирования для изменения свойств
- **Удаление**: выберите файлы и нажмите кнопку удаления
- **Поиск**: используйте строку поиска для быстрого нахождения файлов

## Управление пользователями

### Создание пользователя

1. Перейдите в **Users & Permissions plugin** → **Users**
2. Нажмите кнопку **Create new user**
3. Заполните поля:
   - **Username** - логин
   - **Email** - email
   - **Password** - пароль
   - **Confirmed** - подтверждение email
4. Выберите роль пользователя
5. Нажмите **Save**

### Роли и права доступа

#### Администратор
- Полный доступ ко всем функциям
- Управление пользователями и ролями
- Настройка системы

#### Контент-менеджер
- Создание и редактирование контента
- Управление медиафайлами
- Просмотр статистики

## Работа с редактором контента

### Редактор Rich Text

Редактор поддерживает следующие функции:
- Форматирование текста (жирный, курсив, подчеркивание)
- Заголовки (H1-H6)
- Списки (маркированные и нумерованные)
- Ссылки
- Изображения
- Таблицы
- Цитаты
- Код

### Рекомендации по наполнению контента

1. **Заголовки**: используйте четкие и информативные заголовки
2. **Изображения**: добавляйте альтернативный текст для доступности
3. **Ссылки**: проверяйте правильность ссылок
4. **Форматирование**: используйте единый стиль форматирования
5. **Даты**: указывайте актуальные даты публикаций

## Публикация контента

### Черновики и публикация

- **Draft** - черновик, не виден на сайте
- **Published** - опубликованный контент, виден на сайте

### Отложенная публикация

1. При создании/редактировании контента нажмите **Publish**
2. Выберите **Publish at a specific date**
3. Установите желаемую дату и время публикации
4. Нажмите **Save**

## Безопасность

### Рекомендации по безопасности

1. **Пароли**: используйте сложные пароли, меняйте их регулярно
2. **Доступ**: не передавайте свои учетные данные третьим лицам
3. **Выход**: всегда выходите из системы после завершения работы
4. **HTTPS**: убедитесь, что доступ к админ-панели осуществляется по HTTPS

### Резервное копирование

Система автоматически создает резервные копии базы данных ежедневно в 2:00 ночи. Резервные копии хранятся в папке `backend/backups/`.

## Поиск и устранение проблем

### Частые проблемы

#### Контент не отображается на сайте
- Убедитесь, что контент опубликован (не находится в статусе Draft)
- Проверьте правильность заполнения обязательных полей
- Очистите кэш браузера

#### Изображения не загружаются
- Проверьте размер файла (максимум 10 MB)
- Убедитесь, что формат поддерживается (JPG, PNG, GIF, WEBP)
- Проверьте права доступа к папке uploads

#### Форма обратной связи не работает
- Проверьте настройки email в конфигурации
- Убедитесь, что SMTP сервер доступен
- Проверьте логи ошибок
